产品简介

听纪（AuraNote） 是一款仅支持 macOS、完全本地离线运行的智能会议纪要应用。基于 FunASR（sherpa-onnx）语音识别引擎与 Pyannote 3.0 声纹分离技术，所有音频数据均在本地处理，无需联网，你的会议内容永远不会离开你的设备。

核心功能

🎙️ 实时流式转写

基于 Paraformer Online 的毫秒级流式语音转文字，录音过程中实时上屏，自动标点恢复。

📁 音频文件导入

支持 WAV / MP3 / M4A / FLAC 等多种格式，自动提取录制时间元数据，全自动离线分析流水线。

🧑‍🤝‍🧑 声纹分离

三级声纹分离：能量 VAD → Pyannote 3.0 Neural VAD → eres2net 512维声纹提取 + 增量聚类。多说话人自动标注，已知联系人自动匹配。

📚 声纹人脉库

本地 SQLite 持久化联系人声纹向量，越用越准。支持手动创建、编辑和管理联系人档案。

🤝 会议管理

会议元数据管理、同主题延续录音、完整历史记录持久化存储。

🔥 热词注入

内置热词预设管理器，录音前选择行业分类，ASR 识别时自动注入，大幅提升专业术语准确率。

⚙️ 转写审阅

审阅模式下支持手动编辑文本、调整说话人标签，展示会议元数据与参会人统计。

🏠 离线沙盒存储

全部数据存储于 App 沙盒 Documents 目录，绝不上传，杜绝隐私泄露。

Overview

AuraNote (听纪) is a macOS-only, fully offline, on-device intelligent meeting minutes app. Built on FunASR (sherpa-onnx) speech recognition and Pyannote 3.0 voiceprint diarization technology, all audio data is processed locally — no network required, your meeting content never leaves your device.

Core Features

🎙️ Real-Time Streaming ASR

Millisecond-level Paraformer Online streaming transcription with automatic punctuation restoration during recording.

📁 Audio File Import

Supports WAV / MP3 / M4A / FLAC and more. Auto-extracts recording metadata and triggers offline analysis pipeline.

🧑‍🤝‍🧑 Speaker Diarization

Three-stage pipeline: Energy VAD → Pyannote 3.0 Neural VAD → eres2net 512-dim embeddings + incremental clustering. Auto-labeling and known-contact matching.

📚 Voiceprint Library

Persistent local SQLite voiceprint storage. Improves with use. Full contact profile management.

🤝 Meeting Management

Metadata management, continuous recording for multi-session meetings, persistent history storage.

🔥 Hotword Injection

Built-in hotword preset manager with industry categories. Auto-injected during ASR for superior domain terminology accuracy.

⚙️ Transcript Review

Full editing capabilities in review mode. Adjust speaker labels, view metadata and participant statistics.

🏠 Offline Sandbox Storage

All data stored in App sandbox Documents directory. Never uploaded. Zero privacy leaks.

Processing Pipeline

Live Recording Mode:
  Mic → Gain/Denoise → Resample (16kHz)
      ├─→ [Streaming ASR] Paraformer Online → Real-time text
      └─→ [VAD Cuts] Batch 8s → Pyannote + eres2net → Speaker labels
  ↓ Stop Recording
  [Offline Refinement] Full audio → Pyannote + eres2net + Clustering
              ↓ Voiceprint chunks
         Paraformer Offline → High-precision → Alignment → Contact matching

File Import Mode:
  Audio file → Metadata extraction → AVAssetReader decode → Same offline pipeline
